# Final project

Final project: Розробка та впровадження веб-додатку на основі штучного інтелекту


Орієнтовна тривалість: 1 година 45 хвилин
Сценарій

Вас найняла компанія з електронної комерції на посаду інженера-програміста для створення веб-додатку на базі штучного інтелекту, який виконує аналіз відгуків клієнтів щодо їхніх фірмових продуктів. Щоб виконати це завдання, ви створите систему розпізнавання емоцій, яка оброблятиме відгуки, надані клієнтом у текстовому форматі, та розшифровуватиме пов’язані з ними емоції.
Вступ

У цьому фінальному проекті вас оцінюватимуть за знаннями, отриманими щодо всіх аспектів створення додатків та їхнього розгортання у веб-середовищі протягом цього курсу, і ми використовуємо вбудовані бібліотеки штучного інтелекту Watson для створення додатка для виявлення емоцій.

Виявлення емоцій розширює концепцію аналізу настроїв, виокремлюючи з висловлювань більш тонкі емоції, такі як радість, смуток, гнів тощо, на відміну від простої полярності, яку надає аналіз настроїв. Це робить виявлення емоцій дуже важливою галуззю досліджень, і підприємства широко використовують такі системи для своїх систем рекомендацій на основі штучного інтелекту, автоматизованих чат-ботів тощо.

# Завдання 2: Створіть додаток для виявлення емоцій, використовуючи бібліотеку Watson NLP

Бібліотеки Watson NLP вбудовані. Тому немає потреби імпортувати їх у ваш код. Вам потрібно лише надіслати запит POST до відповідної функції в бібліотеці та отримати результат.

plaintext

URL: “https://sn-watson-emotion.labs.skills.network/v1/watson.runtime.nlp.v1/NlpService/EmotionPredict”
Заголовки: {«grpc-metadata-mm-model-id»: «emotion_aggregated-workflow_lang_en_stock»}
Вхідні дані у форматі JSON: { «raw_document»: { «text»: text_to_analyze } }

Зверніть увагу, що text_to_analyze використовується як змінна, яка містить фактичний текст, що підлягає аналізу.

У файлі emotion_detection.py напишіть функцію для виконання виявлення емоцій, використовуючи відповідну функцію Emotion Detection. Назвіть цю функцію emotion_detector.

Примітка: Припустімо, що текст, який потрібно проаналізувати, передається до функції як аргумент і зберігається у змінній text_to_analyze. Значенням, що повертається, має бути атрибут text об’єкта response, отриманого від функції Emotion Detection.
