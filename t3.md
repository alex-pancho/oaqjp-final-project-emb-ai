# Завдання 3: Форматування виходу програми

## Опис завдання

1. Перетворіть текст відповіді API у словник за допомогою функцій бібліотеки `json`.

2. Проаналізуйте структуру отриманого словника.

3. Витягніть такі емоції разом з їхніми оцінками:
   - `anger` (гнів)
   - `disgust` (огида)
   - `fear` (страх)
   - `joy` (радість)
   - `sadness` (сум)

4. Реалізуйте логіку для визначення **домінуючої емоції** — емоції з найбільшим значенням score.

5. Оновіть функцію `emotion_detector`, щоб вона повертала результат у такому форматі:

```python
{
    'anger': anger_score,
    'disgust': disgust_score,
    'fear': fear_score,
    'joy': joy_score,
    'sadness': sadness_score,
    'dominant_emotion': '<назва домінуючої емоції>'
}
````

```python

```

```python

    'anger': 0.001,
    'disgust': 0.002,
```
