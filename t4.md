# Завдання 4: Упакування застосунку

У цьому завданні потрібно упакувати застосунок, створений на попередніх етапах.

## Кроки виконання

1. Виконайте необхідні дії для створення Python package.

2. Встановіть назву пакета:

```text
EmotionDetection
````

---

## Оцінювання

### Варіант 1 — AI Graded Submission and Evaluation

### Activity 1

Переконайтеся, що ви завантажили файл:

```text
__init__.py
```

у свій forked GitHub repository відповідно до інструкцій лабораторної роботи.

Після цього скопіюйте та збережіть публічний GitHub URL файлу `__init__.py`, який містить код для імпорту модуля застосунку.

Цей URL використовується для фінального submission та evaluation.

---

### Activity 2 — Перевірка пакета

Щоб перевірити, що `EmotionDetection` є валідним пакетом:

1. Запустіть оболонку Python:

```bash
python3
```

2. Імпортуйте функцію:

```python
from EmotionDetection import emotion_detector
```

> Якщо пакет створено правильно, помилок бути не повинно.

3. Протестуйте функцію з текстом:

```text
I hate working long hours.
```

4. Переконайтеся, що у відповіді:

```text
dominant_emotion = anger
```

---

### Submission для AI grading

Скопіюйте terminal output, який підтверджує:

* успішний імпорт пакета
* успішний запуск функції
* правильний результат з `dominant_emotion = anger`

Збережіть output у текстовому файлі:

```text
4b_packaging_test
```

для фінального submission.
