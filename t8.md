# Завдання 8: Виконання статичного аналізу коду

Нарешті, час перевірити відповідність коду.

Виконайте статичний аналіз коду, який ви створили. Використовуйте бібліотеку PyLint на файлі server.py і намагайтеся отримати оцінку 10/10. Вам потрібно буде змінити файл server.py, щоб отримати цю оцінку.

Оцінювання:

Для Варіанту 1 - Оцінка штучним інтелектом: Скопіюйте та вставте код з файлу server.py, що демонструє виконання статичного аналізу коду, у текстовий файл і збережіть його як 8a_server_modified для подачі та оцінювання фінального проєкту.

Для Варіанту 2 - Оцінка однолітками: Зробіть скріншот модифікованого файлу та назвіть його 8a_server_modified.png для завдання від однолітків.

Примітка: Різниця між оцінкою 9/10 та 10/10 може полягати в використанні Docstrings. Додайте Docstrings у всі функції вашого коду.

Оцінювання:

Для Варіанту 1 - Оцінка штучним інтелектом: Скопіюйте та вставте вивід терміналу, що показує ідеальну оцінку для статичного аналізу коду, у текстовий файл і збережіть його як 8b_static_code_analysis для подачі та оцінювання фінального проєкту.

Для Варіанту 2 - Оцінка однолітками: Зробіть скріншот виводу 10/10 у терміналі після виконання статичного аналізу коду. Назвіть скріншот 8b_static_code_analysis.png для завдання від однолітків.
