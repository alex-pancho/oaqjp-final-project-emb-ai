# Завдання 2: Створення додатка для виявлення емоцій за допомогою бібліотеки Watson NLP

Бібліотеки Watson NLP вже вбудовані, тому імпортувати їх у код не потрібно. Необхідно лише надіслати **POST-запит** до правильної функції бібліотеки та отримати результат.

## Дані для використання функції Emotion Predict

Для цього проєкту використовується функція **Emotion Predict** бібліотеки Watson NLP.

### Налаштування запиту

```text
URL: https://sn-watson-emotion.labs.skills.network/v1/watson.runtime.nlp.v1/NlpService/EmotionPredict
Headers: {"grpc-metadata-mm-model-id": "emotion_aggregated-workflow_lang_en_stock"}
Input JSON: {"raw_document": {"text": text_to_analyze}}
````

> **Примітка:** `text_to_analyze` — це змінна, яка містить текст для аналізу.

## Кроки виконання

1. Створіть файл `emotion_detection.py` у папці `final_project`.

2. У файлі `emotion_detection.py` напишіть функцію для визначення емоцій за допомогою функції Emotion Detection.

3. Назвіть функцію:

```python
emotion_detector
```

4. Передавайте текст для аналізу у функцію як аргумент і зберігайте його у змінній:

```python
text_to_analyze
```

5. Функція повинна повертати:

```python
response.text
```

тобто атрибут `text` об'єкта відповіді, отриманого від Emotion Detection API.

## Якщо виникла помилка `ModuleNotFoundError`

Якщо Python показує:

```text
ModuleNotFoundError: No module named 'requests'
```

встановіть бібліотеку `requests` командою:

```bash
python3 -m pip install requests
```
