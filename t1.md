# Завдання 1: Fork і Clone репозиторію проєкту

GitHub-репозиторій проєкту доступний за URL нижче. Як перший крок, вам потрібно зробити **Fork** цього репозиторію, натиснувши кнопку **Fork** у правому верхньому куті сторінки репозиторію.

```bash
https://github.com/ibm-developer-skills-network/oaqjp-final-project-emb-ai.git
````

Інструкції щодо створення форка можна знайти в **Exercise 2** лабораторної роботи: **Get familiar with Git Commands**.

> **Примітка:** Переконайтеся, що ваш forked-репозиторій є **Public**.
> Ця дія створить копію репозиторію у вашому GitHub-акаунті.

## Кроки

1. Відкрийте новий термінал і створіть директорію `final_project` за допомогою команди `mkdir`.

2. За допомогою терміналу Cloud IDE виконайте клонування вашого forked GitHub-репозиторію у папку з назвою `final_project`.

   Інструкції щодо отримання clone URL можна знайти в **Exercise 3** лабораторної роботи: **Get familiar with Git Commands**.

3. Після завершення клонування перейдіть у директорію `final_project` через термінал.

4. Відкрийте у своєму forked-репозиторії файл `README.md` і додайте назву проєкту:

```text
Final project
```

> **Важливо:** Використовуйте саме цю назву без змін, оскільки це обов’язкова вимога для AI-graded submission.

## Оцінювання

### Варіант 1 — AI Graded Submission and Evaluation

Скопіюйте та збережіть публічний GitHub URL файлу `README.md`, який містить назву проєкту **Final project**, для подання та оцінювання фінального проєкту.

### Варіант 2 — Peer-Graded Submission and Evaluation
