# Завдання 7: Впровадження обробки помилок

Потрібно реалізувати обробку помилок у функції `emotion_detector`, щоб коректно працювати з порожнім вводом користувача (коли застосунок запускається без тексту).

---

## Вимоги до `emotion_detector`

1. Отримайте атрибут:

```python
response.status_code
````

2. Якщо:

```python
status_code == 400
```

функція повинна повертати словник того ж формату, але всі значення мають бути `None`.

Очікуваний формат:

```python
{
    'anger': None,
    'disgust': None,
    'fear': None,
    'joy': None,
    'sadness': None,
    'dominant_emotion': None
}
```
