# Завдання 5: Запуск модульних тестів у програмі

Тепер, коли застосунок працює, потрібно виконати модульне тестування, щоб перевірити правильність результатів.

## Кроки виконання

1. Створіть новий файл:

```text
test_emotion_detection.py
````

2. У файлі викличте функцію з пакета `EmotionDetection` та протестуйте її на наведених висловлюваннях.

## Тестові дані

| Висловлювання                            | Очікувана домінуюча емоція |
| ---------------------------------------- | -------------------------- |
| I am glad this happened                  | joy                        |
| I am really mad about this               | anger                      |
| I feel disgusted just hearing about this | disgust                    |
| I am so sad about this                   | sadness                    |
| I am really afraid that this will happen | fear                       |


## Приклад логіки тестів

Файл `test_emotion_detection.py` повинен перевіряти:

* `joy`
* `anger`
* `disgust`
* `sadness`
* `fear`

через виклик:

```python
emotion_detector()
```

та порівняння значення:

```python
dominant_emotion
```
